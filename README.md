# CS2-Aviles-LucasSebastian

## Description
This program calculates the total cost of your electricity bill

## Version 1 - Original code without input validation
- Input: Accepts a customer's name, previous electricity reading, and current reading
- Process: Subtracts the previous reading from the current reading and multiplies it by the rate (P12.90 per watt), then displays the product (total bill) rounded to two decimal points.
- Output: Total bill
- Input Validation: none
